# 首批可靠性改造验收

基于 `menggou1/ua3f-windows` 的 `7e5e202`，在 Windows amd64 上验证。
工具链：Go 1.27.3；race 使用 LLVM-MinGW 20261006 / Clang 23.1.3。
便携工具链位于当前账户 LocalAppData 的 `Codex/Toolchains/ua3f`，未修改系统 PATH。

## 本轮完成

- 驱动文件按内嵌内容进行 SHA-256 校验，临时文件校验后再替换；覆盖同长度损坏、只读失败及非普通文件测试。
- 只读查询 WinDivert 服务配置和状态，识别失效旧路径与其他应用的有效路径；不自动改动服务。
- Runner 按运行会话串行管理启动与停止，覆盖启动取消、重复停止、接收异常、包循环 panic、关闭失败重试与退出等待。
- 保留本地 godivert 的现有接口与 ABI，只补 DLL 必需导出预检查和句柄开关的原子访问；没有升级驱动依赖。
- 所有本地 API 使用会话令牌，增加 Host/Origin 校验、跨站拒绝、请求方法检查、配置体积限制和单 JSON 值约束。
- HTTP 仅在完整请求头内精确匹配 UA 字段，校验 IPv4/TCP 长度并跳过分片的 UA 改写，移除变长负载路径，修正 TTL 增量校验和。
- Windows CI、构建脚本与人工恢复说明。
